Directory categories & single-root library

Design for merging the Komga/Calibre pile into one curated tree and teaching Folio to treat path segments as shelves. Accepts a full rescan (broken book_files.path is fine).

Goals & non-goals

Goals

  • One SCAN_ROOT — single bind mount; dumps stay outside or under non-scanned hold dirs.
  • Categories from directories — no free-text tag soup; path is the product model.
  • Author remains metadata (and usually a folder under the category), not the top browse axis.
  • Folio-first (YOUR_HOST). Komga may share the tree later; do not shape layout for comic “series = folder” semantics.
  • Full rescan OK — wipe or rebuild import_files / external book_files after the tree rewrite.

Non-goals (v1)

  • Multi-category membership per book (one primary shelf only).
  • Auto-classifier in production (heuristics may assist offline migration only).
  • Preserving current absolute paths or Calibre (id) folder names in the product tree.
  • Importing all historical dumps on day one.

Rule books.category is always category or category/subcategory (slash-joined, lowercase kebab keys from taxonomy). Never includes author or title segments.

Calibre leftover dirs

If a directory still contains metadata.opf, treat the whole dir as one book (today’s scan behaviour). Category segments are only those above the author folder: 

fiction/sf/Isaac Asimov/Foundation (42)/metadata.opf
→ category = "fiction/sf"
→ author/title from OPF (not from folder names)

Product migration should drop Calibre (id) leaves and use flat Author/Title.ext under the category; OPF optional.

Schema: books.category

Column

add_column :books, :category, :string
add_index  :books, :category
  • Type: string, nullable (uploads with no path context → nil or _inbox).
  • Value: \A[a-z0-9_]+(?:/[a-z0-9_]+)?\z or empty.
  • Not a join table in v1 — single primary shelf only.

Model helpers

# app/models/book.rb
def category_parts
  category.to_s.split("/", 2)
end

def category_root
  category_parts.first
end

def display_category
  category.presence || "Uncategorized"
end

Editable?

Yes — include :category in book_params. Manual override wins until the next rescan of that file’s path (scan should refresh category from path on re-import of changed/new files; do not clobber on “unchanged” skip path).

Policy Path is source of truth for scanned books. UI edit is for edge cases; if path and DB disagree after a move, rescan repairs DB.

Scan parse rules

Extend Library::Scan / Library::Ingest — category computed once per group, passed into book create/update.

Algorithm

def category_for(path, roots:)
  root = roots.find { |r| path.start_with?(r.to_s + "/") }
  return nil unless root

  rel = Pathname.new(path).relative_path_from(root)
  parts = rel.each_filename.to_a
  return "_inbox" if parts.first == "_inbox"
  return nil if parts.first&.start_with?("_", ".")

  # Drop file name
  parts = parts[0..-2]

  # Calibre leaf: Author / Title (id) / file → drop last dir if opf sibling group
  # Author folder is always last remaining dir under category segments.
  depth = ENV.fetch("CATEGORY_DEPTH", "2").to_i.clamp(1, 2)

  if parts.size >= depth + 1
    # category… + author [+ title-dir]
    parts[0, depth].join("/")
  elsif parts.size == depth
    # category… only (loose file under subcategory — discouraged)
    parts[0, depth].join("/")
  elsif parts.size >= 1
    parts[0]
  end
end

Optional taxonomy validation

Load config/library_taxonomy.yml (copy of docs YAML). If category ∉ known set and ≠ _inbox, log warning and still store (forward-compatible) or map to _inbox when CATEGORY_STRICT=1.

Interaction with existing grouping

  • Unchanged: OPF dir → one book; same-stem formats → one book.
  • New: set book.category on create; on attach-to-existing book, if category blank, fill from path.
  • Do not split one OPF book across categories (impossible if one dir).

UI filter & navigation

Library index (BooksController#index)

  • Param: category (exact string, e.g. fiction/sf).
  • Optional: category_root = first segment only (WHERE category = ? OR category LIKE ? with fiction/%).
  • Filter chips / select: list distinct categories with counts (Book.group(:category).count, cached with library_stats).
  • Keep existing filters (author, series, format, year, language); compose with AND.
  • “Keep reading” shelf: still only on fully unfiltered home (include category in the guard).

Device API

Search & embeddings

  • FTS5: add category column to book_search; include in metadata scope match.
  • Embeddings: prepend category label to the embed text ([fiction/sf] title author…) so “meaning” search can bias shelves lightly.
  • Reindex job after migration: batch IndexBookJob / embed — overnight OK.

Cutover / migration

Disk

  1. Create new tree (host): e.g. /path/to/library/books/ per taxonomy.
  2. Phase 1: hardlink/copy from main Calibre + book/ with author normalize.
  3. Phase 2: second Calibre with sha256 dedupe.
  4. Phase 3: dumps optional → else leave under _quarantine or old paths unmounted.

Folio

  1. Deploy category column + scan/UI code.
  2. Point SCAN_ROOTS=/books (bind new tree only).
  3. Reset scan ledger for external files (or full DB book_files path rebuild):
    • Delete import_files rows for old /komga/… paths, or
    • Accept missing → prune, then clean scan.
  4. Full scan; verify category histogram.
  5. Run duplicate merge catalog op; author cleanup pass.
Warning Do not move files under the currently mounted tree while a scan runs. Build the new tree beside the old one; switch the mount/env in one deploy.

Implementation checklist

  2. Library::Category.from_path(path, roots:) pure module + specs (table above).
  3. Wire into Library::Scan#import_group / Ingest#build_book.
  4. BooksController#index filter + stats cache key include category breakdown.
  5. Views: filter control, show breadcrumb, edit field.
  6. BookSearch schema + reindex path.
  7. Embeddings text prefix.
  8. Copy library-taxonomy.yml → config/ if strict validation desired.
  9. Compose: SCAN_ROOTS=/books, CATEGORY_DEPTH=2, bind new host path.

Specs (minimum)

  • Path → category matrix (incl. _inbox, deep author, OPF leaf).
  • Index filter by category and category_root.
  • Scan creates book with category set; unchanged skip does not clear category.
